# 0단계: PRD 작성 (사람이 승인하는 기준 문서)
```
지금부터 React 프론트엔드 작업을 진행할 거야.

먼저 .planning/prd.md를 작성해줘. 아래 정보를 바탕으로:

- 목표: chat_ui_설계도.jpg 기준 채팅 UI 화면 구현
- 대상 사용자/사용 시나리오: [간단히 기술]
- 필수 기능 요구사항(Must-have) / 있으면 좋은 것(Nice-to-have) 구분
- 비기능 요구사항: [반응형 여부, 성능, 접근성 등]
- 범위 제외 사항: 백엔드는 이미 완성되어 있으므로 API 변경 요구는 제외, 
  프론트엔드(/frontend 등 실제 경로) 파일만 수정

작성 후 나에게 먼저 보여주고, 내가 승인하면 다음 단계로 넘어가줘.
아직 다른 파일은 만들지 마.
```

# 1단계: 3-file-system 생성 + 통제 규칙 명시
```
prd.md가 승인됐으니, .planning/ 폴더에 task_plan.md, findings.md, 
progress.md 3개 파일을 생성해줘. 아직 내용은 채우지 말고 빈 파일만.

[전체 작업 규칙]
- 작업 범위: /frontend (실제 경로로 수정) 이하 파일만 수정, 백엔드는 절대 건드리지 마
- 디자인 참고: chat_ui_설계도.jpg
- 라이브러리/프레임워크 문법은 반드시 Context7 MCP로 최신 공식 문서를 
  조회한 뒤 사용해. 학습 데이터 기억에 의존해서 코드 작성 금지
- prd.md 요구사항과 어긋나는 작업은 하지 마
- 백엔드 스펙이 필요하거나 애매한 부분은 임의로 진행하지 말고 
  findings.md에 이슈로 기록 후 나에게 먼저 물어봐
```

# 2단계: findings.md — 조사 (이미지 분석 + Context7)
```
findings.md에 아래 내용을 조사해서 채워줘:

1. chat_ui_설계도.jpg를 분석해서:
   - 화면 구성 요소(컴포넌트) 목록
   - 레이아웃 구조
   - 인터랙션 요소 (입력창, 버튼, 스크롤 영역 등)

2. Context7 MCP로 다음 라이브러리의 최신 문서를 조회하고 핵심 사용법 요약:
   - [예: React 19, Tailwind CSS, 상태관리 라이브러리 등]

3. 기존 프론트엔드 코드가 있다면 구조/컨벤션 파악해서 기록

아직 코드는 작성하지 말고 조사 결과만 기록해줘.
```

# 3단계: task_plan.md — 계획 수립
```
prd.md와 findings.md를 바탕으로 task_plan.md를 작성해줘.

- prd.md의 Must-have 요구사항을 모두 충족하는 컴포넌트 단위 체크리스트
  (예: ChatLayout → MessageList → InputBox → 상태관리 연결 → 스타일링)
- Nice-to-have는 별도로 표시해서 우선순위 낮게 배치
- 각 항목마다 사용할 기술/라이브러리 명시 (Context7 조사 결과 기반)
- 백엔드 연동이 필요한 부분은 "확인 필요"로 표시, 실제 연동은 Mock 데이터로 대체

계획만 작성하고, 내가 확인하기 전까지 코드는 작성하지 마.
```

# 4단계: 구현 (컴포넌트 단위 반복 루프)
```
task_plan.md 체크리스트의 1번 항목만 구현해줘.

- 구현 전 prd.md 요구사항과 어긋나지 않는지 확인
- Context7로 관련 라이브러리 최신 API 재확인
- chat_ui_설계도.jpg 디자인을 최대한 정확히 반영
- 완료 후 progress.md에 완료 내용/다음 할 일 업데이트
- 막히면 findings.md에 이슈 기록 후 나에게 질문
```
